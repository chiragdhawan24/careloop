# CareLoop

CareLoop is a closed-loop diagnostic follow-up and patient-safety platform built with C# and .NET.

The system is designed to track diagnostic workflows from order creation through result review, patient communication, follow-up, escalation, and final resolution.

## Technology

- C#
- .NET 10
- ASP.NET Core
- Blazor
- Entity Framework Core
- PostgreSQL
- Aspire
- HL7 FHIR

## Architecture

CareLoop uses a modular monolith architecture with clear separation between:

- Domain
- Application
- Infrastructure
- API
- Web
